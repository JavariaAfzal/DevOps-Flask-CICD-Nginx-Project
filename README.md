# DevOps Flask CI/CD Nginx Project

## Project Overview

This project demonstrates a practical DevOps workflow for a Flask web application using Docker, Nginx, GitHub, and CI/CD automation.

The application is containerized using Docker, while Nginx is configured as a reverse proxy to forward requests to the Flask application.

## Technologies Used

- Python
- Flask
- Git
- GitHub
- Docker
- Nginx
- GitHub Actions
- Render

## Project Workflow

Flask Application → Git → GitHub → GitHub Actions → Docker → Nginx → Render

## Features
Flask web application
Git-based version control
GitHub repository management
Docker containerization
Docker networking
Nginx reverse proxy
CI/CD automation with GitHub Actions
Cloud deployment using Render

## Learning Outcomes
Understanding the DevOps development workflow
Practicing Git and GitHub version control
Understanding Docker images and containers
Working with Docker networking
Configuring Nginx as a reverse proxy
Understanding CI/CD automation
Deploying an application to the cloud
